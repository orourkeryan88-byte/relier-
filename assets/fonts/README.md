# Fonts

Self-hosted so the site makes **no third-party requests**. Loading fonts from
the Google Fonts CDN sends every visitor's IP address to Google, which German
courts have held to breach the GDPR, and it also forces a looser
Content-Security-Policy. These files remove both problems.

| File | Family | Licence |
|---|---|---|
| `archivo-var.woff2` | Archivo (variable, wght 100–900) | SIL Open Font License 1.1 |
| `public-sans-var.woff2` | Public Sans (variable, wght 100–900) | SIL Open Font License 1.1 |

Both are OFL-licensed, which permits redistribution and self-hosting.
Latin subset only (covers English and Irish, including fadas).
Source: Google Fonts.
